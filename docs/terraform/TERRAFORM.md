# Terraform — core commands

For what the files and folders generated by Terraform mean, see [CORE_CONCEPTS.md](CORE_CONCEPTS.md).

## Basic workflow

| Command | What it does |
|---|---|
| `terraform init` | Initializes the working directory: downloads providers (and modules) into `.terraform/`, creates `.terraform.lock.hcl`. Run it first, and again after changing providers/modules/backend. |
| `terraform plan` | Shows what Terraform will change (create `+`, update `~`, destroy `-`) without applying anything. |
| `terraform apply` | Shows the plan and, after you confirm with `yes`, creates/updates infrastructure. Updates `terraform.tfstate`. |
| `terraform destroy` | Destroys all resources managed by this configuration (after confirmation). |

## Checking and formatting code

| Command | What it does |
|---|---|
| `terraform fmt` | Formats `.tf` files to the standard style (indentation, `=` alignment). `-recursive` also formats subfolders. |
| `terraform validate` | Checks syntax and internal consistency of the configuration. Requires `init`. |

## Inspecting state

| Command | What it does |
|---|---|
| `terraform show` | Shows the current state of resources from `terraform.tfstate` in a readable form. |
| `terraform state list` | Lists all resources in state (e.g. `docker_container.nginx`). |
| `terraform state show <resource>` | Shows detailed attributes of one resource: `terraform state show docker_container.nginx`. |
| `terraform output` | Prints the values of `output` blocks (from `outputs.tf`). `terraform output container_id` prints a single value. |

## Variables

| Command | What it does |
|---|---|
| `terraform apply -var "container_name=YetAnotherName"` | Passes a variable value from the command line, overriding the `default` in `variables.tf`. |
| `terraform apply -var-file="dev.tfvars"` | Reads variable values from a file. `terraform.tfvars` is loaded automatically. |

## Useful flags

| Flag | What it does |
|---|---|
| `-auto-approve` | For `apply`/`destroy`: skips the `yes` prompt. Use with care. |
| `plan -out=tfplan` + `apply tfplan` | Saves the plan to a file and applies exactly that plan. |
| `init -upgrade` | Upgrades providers to the newest version allowed by the `version` constraint and rewrites the lock file. |
